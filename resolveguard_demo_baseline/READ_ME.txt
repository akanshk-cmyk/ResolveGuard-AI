ResolveGuard learning/demo baseline

All business volumes, costs, queue hours, targets and operating rules are invented demo assumptions, not measured banking benchmarks or approved policy.

Files:
- baseline_assumptions.json: scope, planning baseline, synthetic operations, stack choices and proposed demo acceptance.
- expected_evaluations_100.json / .csv: unchanged expected guardrail rows exported from the supplied workbook; all Not Run. These do not bind all cases to executable fixtures.
- synthetic_intake_handoff_examples.json: six expected state examples linked to existing session/transaction fixtures. These are not observed events or legal determinations.

The original PDFs, workbook and fixture tools are unchanged. This package does not implement an app, repair workbook formulas, execute model evaluations, or establish bank approval.

Validation: 100 unique case IDs; 84 critical; 16 standard; all expected statuses Not Run; six event examples have valid references to existing synthetic fixtures.
