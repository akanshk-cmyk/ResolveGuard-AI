uv run --locked --extra evals python -m tools.calibrate_human_review --reviews path/to/completed.csv --output artifacts/new-human-calibration.json

The importer rejects missing attestation, changed sources, duplicate/unknown IDs and invalid marks. It never fills missing human labels itself.
