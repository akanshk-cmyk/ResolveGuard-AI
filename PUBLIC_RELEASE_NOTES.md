# Public Release Provenance and Privacy Notes

This is the public source snapshot for https://github.com/akanshk-cmyk/ResolveGuard-AI.

Application Python, UI assets, test contracts, prompts and canonical banking data are byte-identical to the locally verified source. The private working .env, local databases, browser profiles, logs, credential stores and audit scratch output are excluded. No license was invented; license selection remains open.

Public report and historical evidence copies are **redacted derivatives**, not the original private files. Local user/workspace paths and Office/PDF author/editor metadata were removed, including inside bundled archives. Numeric scores, case IDs, expected labels and review marks were not changed. Originals remain private and unmodified. Source/provenance hashes retained in historical records refer to those originals; PUBLIC_RELEASE_REDACTIONS.json records original/public byte hashes for changed files, without identifying author values.

The optional final-report authoring utility now accepts RESOLVEGUARD_HANDOUT_PATH instead of a personal Downloads path. This input is not required for the app; existing report artifacts are included. Windows font paths in optional drawing utilities are portability details, not internal service addresses.

Nested source checkpoints and submission ZIPs are likewise public derivatives. Their checksum manifests are refreshed where affected. Recreating an exact original-source attestation requires the privately retained original, not a metadata-clean public workbook. Generated report-copy metadata is not new human approval or evaluation execution.

The security audit document describes the pre-cleanup findings. This release addresses its user-home/workspace path and author/editor metadata findings; it does not assert universal security or production readiness. Synthetic dummy credentials used in tests and localhost binding addresses are retained intentionally. No live bank integration or cloud tracing qualification is implied.
